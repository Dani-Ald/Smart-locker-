# Presentación ejecutiva de Smart Ticket

Presentación web de 13 diapositivas y guion independiente. Abre `index.html` directamente en un navegador moderno; no requiere instalación ni conexión a internet mientras se conserve su ubicación dentro del repositorio, ya que utiliza el icono de la aplicación mediante una ruta relativa.

## Controles

- **Siguiente / Anterior:** avanzan o retroceden por las diapositivas y sus etapas.
- **Flechas derecha/izquierda**, **Av Pág/Re Pág** o **espacio:** navegación. En el recorrido móvil también avanzan las pantallas ilustrativas.
- **Inicio / Fin:** primera / última diapositiva.
- **Pantalla completa:** botón en la barra superior, si el navegador lo permite.
- La diapositiva de recorrido móvil incluye controles propios para pasar entre pantallas.

El avance por etapas se utiliza en la diapositiva de alcance, el diagrama de arquitectura y el recorrido móvil. Para imprimir, utiliza **Imprimir → Guardar como PDF** en orientación horizontal; el PDF muestra las diapositivas completas y el estado actual del recorrido móvil, no sus diez escenas por separado.

## Archivos

- `index.html`: estructura y contenido de las diapositivas.
- `estilos.css`: identidad visual, diseño adaptable, movimiento reducido e impresión.
- `presentacion.js`: navegación, animaciones por etapas y recorrido móvil.
- `guion.md`: discurso, tiempos, transiciones, indicaciones para la demostración y fuentes.

## Veracidad y materiales por confirmar

Las cifras citan la encuesta exploratoria de diez asistentes y las entrevistas a tres organizadores. Los teléfonos son recreaciones visuales, no capturas reales. La compra real, la integración web–app, el uso de AES en la wallet, la identificación oficial y el conteo mediante dispositivo físico no se presentan como funcionalidades comprobadas. La referencia NMX no implica certificación.

Las fotografías del equipo no están en el PDF de diapositivas disponible; se utilizan iniciales hasta que se proporcionen las imágenes. Las actividades mostradas proceden de la investigación documentada y no sustituyen la confirmación de roles de desarrollo.
